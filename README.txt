MONI BIRTHDAY WEBSITE UPGRADE

Android GitHub Pages instructions:
1. Open https://github.com/Hackki-stack/moni-birthday
2. Tap index.html, then the pencil/Edit button.
3. Select all old code and replace it with the new index.html contents.
4. Tap Commit changes and confirm.
5. Wait for GitHub Pages to deploy, then refresh the live site. If needed, open it in an Incognito tab.

Important:
- Keep index.html in the repository root. Do not replace it with the ZIP.
- Default secret code is 143. Search for value==='143' in the script and change 143 to your chosen code.
- Gallery uploads selected from the phone preview only in that browser session. To show images to visitors, upload the image files into the repository and edit the gallery markup to reference them.
- Tap the music button and choose an audio file from your phone. Browsers generally block autoplay.
- Edit the letter/timeline text directly in index.html before committing.
- GitHub Pages files are public. The secret code is a fun page reveal, not real security.
